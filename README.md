## 3 Perbedaan Gaya Prosedural dan OOP

1. **Struktur dan Organisasi Kode:**
   * **Prosedural:** Berjalan secara berurutan (*top-down*) menggunakan fungsi global untuk memproses array data. Struktur cenderung tercampur jika skala aplikasi bertambah besar.
   * **OOP:** Diorganisasikan ke dalam *class* dan *object* yang merepresentasikan entitas nyata, membuat kode lebih modular dan terstruktur.

2. **Enkapsulasi dan Keamanan Data:**
   * **Prosedural:** Variabel bersifat global atau mudah diakses langsung dari bagian mana saja, sehingga lebih rentan terhadap perubahan yang tidak disengaja.
   * **OOP:** Data dan fungsi dibungkus di dalam satu kelas (enkapsulasi). Akses dapat dikontrol menggunakan modifier seperti `public` atau `private`.

3. **Reusabilitas dan Skalabilitas:**
   * **Prosedural:** Lebih sulit digunakan kembali pada proyek lain tanpa menulis ulang fungsi jika struktur datanya berubah.
   * **OOP:** Sangat mudah digunakan kembali (*reusable*) dan dikembangkan dalam skala besar karena mendukung konsep pewarisan (*inheritance*) serta instansiasi objek berulang.
